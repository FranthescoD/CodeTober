🚀 CodeTober · 20 Mini Experimentos Web

Pequenos projetos. Novas ideias.
O CodeTober é um desafio pessoal focado no desenvolvimento de 20 mini experimentos de interface web, explorando componentes, estilos modernos, layouts responsivos, animações e interatividade com código limpo.

🎯 Sobre o Desafio

O objetivo principal do CodeTober não é construir sistemas ou aplicações complexas, mas sim se familiarizar, aprender e explorar diferentes possibilidades com HTML, CSS e JavaScript.
Cada projeto é um experimento independente focado em um elemento de UI/UX (como botões, cards, formulários, listas, carregadores e galerias de imagens), servindo de laboratório para testar novas abordagens de design e lógica frontend.

🛠️ Tecnologias e Conceitos Explorados

HTML5 Semântico: Estruturação limpa, acessível e uso de elementos nativos/SVGs.
CSS3 Moderno: Flexbox, CSS Grid, Glassmorphism, animações (@keyframes), transições suaves e variáveis CSS.
JavaScript ES6+: Manipulação de DOM, escutadores de eventos e interatividade dinâmica.
Design de Componentes: Foco na reusabilidade, responsividade e feedback visual para o usuário.
